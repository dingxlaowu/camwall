# 监控墙 CamWall

安卓 RTSP 摄像头监控 App：1 / 4 / 9 分屏，屏幕常亮，自动调亮度。

## 功能

- **添加设备**：填 IP、用户名、密码，选品牌自动带出 RTSP 路径（海康、大华、萤石、宇视、TP-Link，或自定义）。IP 栏也可以直接粘贴完整 `rtsp://` 地址。
- **1 / 4 / 9 分屏**，摄像头多于一屏时左右滑动或点 ◀ ▶ 翻页。
- **双击**某一路画面放大成单画面（主码流高清），再双击还原。
- **单击**显示 / 隐藏顶部菜单（6 秒后自动隐藏）。
- 分屏时默认用**子码流**，单画面用**主码流**。
- 断线 5 秒自动重连；画面卡住 30 秒自动重连。
- **屏幕常亮 + 自动亮度**：
  - 平时保持最低亮度（默认 1%）
  - 触摸屏幕 → 1.5 秒内升到 80%
  - 最后一次触摸后保持 10 秒，再用 50 秒逐渐降回最低（合计 1 分钟）
  - 暗屏时第一下触摸只负责点亮，不会误触翻页 / 放大
  - 以上数值都能在「设置」里改
  - 只改本 App 窗口的亮度，不需要任何系统权限，退出 App 后系统亮度不受影响

## 编译方法（二选一）

### A. Android Studio（推荐）
1. 安装 Android Studio，打开本文件夹
2. 等 Gradle 同步完成（首次需要下载依赖）
3. 手机开启 USB 调试，连上电脑，点 ▶ Run

### B. 不装 Android Studio，用 GitHub 在线编译
1. 新建一个 GitHub 仓库，把本文件夹所有内容（包括隐藏的 `.github` 文件夹）上传
2. 打开仓库的 **Actions** 页面，等 "Build APK" 跑完（约 3–5 分钟）
3. 点进那次运行，在底部 **Artifacts** 下载 `CamWall-apk`，解压得到 APK，发到手机安装

## 常见 RTSP 地址

| 品牌 | 主码流 | 子码流 |
|---|---|---|
| 海康 | `/Streaming/Channels/101` | `/Streaming/Channels/102` |
| 大华 | `/cam/realmonitor?channel=1&subtype=0` | `...subtype=1` |
| 萤石/海康旧款 | `/h264/ch1/main/av_stream` | `/h264/ch1/sub/av_stream` |
| 宇视 | `/media/video1` | `/media/video2` |
| TP-Link | `/stream1` | `/stream2` |

NVR（录像机）多通道：海康把 `101` 改成 `201`、`301`…；大华改 `channel=2`、`3`…

## 注意

- 摄像头需开启 RTSP（海康、大华默认开启；萤石、TP-Link 部分型号要在 App 里打开并设置"设备验证码"作为密码）。
- 视频编码 H.264 / H.265 都支持（H.265 需手机支持硬解）。9 路同时播放建议都用子码流。
- 长期常亮的 OLED 屏幕可能有烧屏风险，低亮度能减轻但不能完全避免；LCD 平板更适合做监控屏。
- 设备密码保存在 App 私有存储中（已关闭系统备份）。
